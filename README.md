# The Contractor's AI Toolkit — marketing site

Static marketing + SEO site for The Contractor's AI Toolkit: a working estimator's
toolkit for putting AI to work in a construction business (any trade).

- `index.html` — sales / landing page
- `articles/` — SEO/AEO articles targeting real contractor searches
- `robots.txt`, `sitemap.xml` — crawl config (welcomes AI answer-engines)

No build step. Deployed on Render as a static site via `render.yaml`.

**Note:** the actual paid product (guide, templates, prompt pack, AI assistant setup)
is delivered to buyers after purchase and is intentionally **not** in this public repo.
